# 人才九宫格（绩效 × 潜力）方法论

九宫格是人才盘点最核心的可视化工具，帮助 HR 与业务负责人一眼识别"该重点投资谁、该稳住谁、该关注谁"。

## 坐标轴定义
- **横轴 = 绩效(Performance)**：当前岗位产出质量与结果达成（来自绩效考核/上级评价，通常由系统外导入）
- **纵轴 = 潜力(Potential)**：未来承担更大/更复杂职责的可能性（由能力测评 24、学习 13、心理资本 18、360 16 等综合推断，系统提供 `calculate-potential` 接口）

## 九个格子与人才策略

```
潜力高 ↑
  │ [高潜人才]   [核心骨干]   [超级明星]
  │ [潜力待挖]   [中坚力量]   [风险]
  │ [待提升]     [稳定贡献]   [绩效不佳]
  └────────────────────────────→ 绩效高
```

| 格子 | 含义 | 人才策略 |
|------|------|----------|
| **超级明星**（高绩效+高潜力） | 当下顶梁柱且未来可期 | 重点保留、加速晋升、定制发展；避免过度透支 |
| **核心骨干**（中绩效+高潜力） | 未来领袖储备 | 给挑战性任务、导师制、轮岗扩面 |
| **高潜人才**（低绩效+高潜力） | 能力强但暂未发挥 | 排查岗位匹配/动机/管理问题，配对教练 |
| **中坚力量**（中绩效+中潜力） | 组织稳定器 | 维持敬业度，适度赋能 |
| **稳定贡献**（低绩效+中潜力） | 可靠执行者 | 明确期望，巩固基本功 |
| **潜力待挖**（中绩效+低潜力） | 需焕发动力 | 重新激发、调整职责或岗位 |
| **绩效不佳**（高绩效+低潜力） | 当下好但难晋升 | 用其所长，规划专业通道而非管理线 |
| **待提升**（低绩效+中潜力） | 表现未达预期 | 绩效改进计划(PIP)，限期改善 |
| **风险**（低绩效+低潜力） | 双低 | 谨慎使用，评估岗位适配或汰换 |

> 注：具体格子命名与阈值可按企业惯例微调；系统默认按绩效/潜力各自三分位落入九格。

## 操作流程（配合系统 API）
1. **建网格**：`POST /api/nine-box/grids` `{ name, dimensions }`
2. **导入绩效**：通过 `POST /api/nine-box/sync-performance` 或手动 `POST /api/nine-box/grids/:id/positions`
3. **算潜力**：`POST /api/nine-box/calculate-potential`（可 `batch-calculate-potential` 批量）
4. **落格**：系统按绩效×潜力自动归位
5. **校准会议**：业务负责人 + HR 共同复核落格，避免单点偏差
6. **导出**：`GET /api/nine-box/grids/:id/export`（带 `Authorization` 头）→ 打印/存档

## 校准会议要点
- 先定标准：绩效与潜力的分级阈值必须全员一致
- 防偏见：避免"光环效应""近因效应"，用测评数据辅助而非替代讨论
- 出动作：每个高潜/风险人员必须对应一个具体发展或改善动作与责任人

## 应用延伸
- **继任规划**：从"超级明星/核心骨干"中挑选关键岗位继任者
- **IDP 触发**：所有非"稳定贡献/中坚"人员，结合测评报告 `developmentRoadmap` 制定个人发展计划
- **招聘补强**：某格空缺过多（如高潜不足）→ 调整招聘标准或外部引入
